01 · Skill Set

I work across three connected layers of modern IT operations: network & security operations, DevSecOps automation, and applied AI. As a NOC Support Administrator – Systems & Networks, I administer LAN/WAN/Wi-Fi infrastructure across Cisco and Huawei switches, routers, and access points — managing VLAN segmentation, IPv4 addressing/subnetting, and firewall rule sets, then triaging Level 1/2 incidents with structured troubleshooting (ping/traceroute, interface and port-channel checks, log analysis) inside SLA — that discipline of keeping systems available shapes everything else I build.

On the automation side, my default instinct is to eliminate anything I'd otherwise do twice: Terraform and Ansible pipelines that turn manual, credential-heavy deployments into repeatable, securely-configured, policy-gated ones. I think in security gates, not gatekeepers — SAST, SCA, IaC scanning, image signing, and DAST built directly into the pipeline, so issues are caught before they ship, and that same rigor carries into the Spring Boot, Node.js, React, and Angular systems I build end to end.

Alongside the platform and network work, I build with AI: a Flask microservice on the Anthropic API that automatically detects security and pipeline findings and proposes remediation, an OpenAI-driven résumé-screening pipeline, and a VGG16 crop classifier reaching 92% accuracy. Across a solo 5-month internship I secured multiple microservices behind 5 automated security gates with zero stored pipeline credentials — the same standard of rigor I now apply to keeping live network infrastructure available and secure.
